Formation Java Spring Boot à Marseille

Maîtrisez le développement d'applications Web avec Spring Boot. Cette formation vous accompagne des fondamentaux du framework jusqu'au déploiement d'une API REST complète, à travers des projets concrets encadrés par nos formateurs (Alejandro Seijo, Jean-César Bazin et Aubry Capitone) à Marseille.

Au programme : injection de dépendances, accès aux données avec Spring Data, Spring Web, sécurisation des endpoints avec Spring Security et mise en production. Prérequis: Programmation Orientée Object, Java.
